## Краткое описание
Вы ведь видели стримеров или ютуберов, у которых в мире происходил полный хаос при донате от зрителей? За это отвечает [Crown Control](https://crowdcontrol.live/), правда только для Java издания игры :(
(Многие скажут что оно так же поддерживает и Bedrock издание, и будут абсолютно правы)

Данный плагин написан под ядро [PocketMine-MP](https://pmmp.io/) 5-ой версии.
